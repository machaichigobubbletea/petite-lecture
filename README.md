# Petite Lecture

フランス語の短い物語を読みながら語句を学ぶ、スマートフォンにも追加できる学習アプリです。ログインやデータベース、追加パッケージは必要ありません。学習履歴と言語設定はこのブラウザの localStorage に保存されます。

## 起動方法

1. Node.js が入っているパソコンで、このフォルダを開きます。
2. ターミナルで node server.js を実行します。
3. ブラウザで http://127.0.0.1:4173 を開きます。
4. 終了するときは、ターミナルで Ctrl + C を押します。

## スマートフォンで使う

このアプリはPWAに対応しており、対応ブラウザからホーム画面に追加するとアプリのように起動できます。インストールにはHTTPSで公開されたURLが必要です（localhostを除く）。公開URLをスマートフォンで開き、ブラウザの「ホーム画面に追加」または「アプリをインストール」を選んでください。iPhoneではSafariの共有メニューから「ホーム画面に追加」を選びます。追加後は教材をオフラインでも開けます。

同じWi‑Fiにつないだスマートフォンで試すには、パソコンで `node server.js` を起動し、表示される `Phone (same Wi-Fi)` のURLをスマートフォンのブラウザーで開いてください。パソコンのファイアウォールが確認を表示した場合は、プライベートネットワークでのアクセスを許可します。この方法ではアプリ画面を試せますが、ホーム画面へのインストールには使えません。

ホーム画面に追加して使うには、このアプリをHTTPS対応のWebホスティング先に配置してください。

## 教材と翻訳の場所

- books/sample-book/chapter-1.js — 第1章の教材項目と8文の物語。項目には type、フランス語、ja/en の訳と説明を定義します。
- i18n/ui.js — 画面の日本語・英語表示をまとめています。
- app.js — 画面表示、クイズ、音声、復習間隔、進捗保存の処理です。
- styles.css — スマートフォンとPC向けのレイアウトです。

新しい章は books/sample-book/chapter-2.js のような教材ファイルを作り、index.html で読み込んでください。説明言語を増やすときは教材項目と i18n/ui.js に新しい言語キーを追加します。

## 補足

このMVPは、依存パッケージを増やさずすぐ試せるよう、Next.js/TypeScript/Tailwindではなく、素のJavaScriptとCSSで構成しています。教材・UI翻訳・表示処理を別ファイルに分けているため、まず内容を編集しながら使えます。音声認識はブラウザによって非対応の場合があります。正確な発音採点は行いません。
